Files modified by srcradar (relative to upstream code/ tree):

1. common/config.go
   - 1-line change: added "qimai" to the ENSApps list
   - var ENSApps = []string{"miit"}  →  var ENSApps = []string{"miit", "qimai"}
   - Effect: enables the qimai (七麦) app module; without this line the
     qimai module added in #2/#3/#4 below would not be reachable.

2. internal/app/qimai/qimai.go
   - Full rewrite (~140 lines): original three top-level functions
     (GetInfoByKeyword / GetInfoByCompanyId / getInfoList) replaced
     with a Qimai struct implementing the v2 ENScan App interface:
       GetENMap / searchCompanyId / GetInfoList / GetInfoByPage /
       fetchAppList
   - Effect: matches the interface contract that db_align expects when
     shelling out to ENScan; upstream's original function signatures
     were incompatible with srcradar's runner.go consumer.

3. internal/app/qimai/utils.go
   - Companion change to #2: removed local type definitions (EnsGo,
     EnInfos, GetData) that were promoted into the common package
     (so qimai.go's struct methods can share them); updated getENMap()
     to return common.EnsGo instead of the local type.
   - Misc: dropped unused "github.com/tidwall/gjson" import; modernised
     "for k, _ := range" → "for k := range" (Go 1.22+ lint).

4. runner/runner.go
   - 2-line change:
       a) imported "github.com/wgpsec/ENScan/internal/app/qimai"
       b) registered the app: "qimai": &qimai.Qimai{Options: op}
          in the runner's apps map.
   - Effect: wires the qimai module into the dispatch map. Without
     this line the new qimai.go code would never be called.

────────────────────────────────────────────────────────────────────
Rationale
────────────────────────────────────────────────────────────────────

Enable qimai (七麦 / qimai) as a data source for db_align's ENScan
wrapper. The upstream ENScan_GO at the vendor commit did not include
qimai integration; srcradar added it to extend db_align's data
source coverage to APP metadata (应用宝 / App Store metadata).

The rewrite of qimai.go (#2) is the only substantive change. The
other three files (#1, #3, #4) are the supporting wiring needed to
make #2 reachable.
